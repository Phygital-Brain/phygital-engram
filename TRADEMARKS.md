## The name and logo

The license covers the code and text. It does not cover the Phygital Engram name or the logo (in `docs/images/`). The license gives no permission to use them.

## Always say where it came from

Any project that uses Phygital Engram, changed or not, must say so in its README or about page, with a link to this repository. Use one of these: "built on Phygital Engram", "based on Phygital Engram" or "a fork of Phygital Engram".

This applies to every project.

## You can

- Use, change and share the code and text, under the license.
- Say true things about it, like the lines above.
- Show the logo next to a link to this repository, unchanged, when you talk about the project.

## You can't, without written permission

- Sell, offer or name a product, service, course or setup as "Phygital Engram", or with a name that could be mixed up with it.
- Use the logo, or something close to it, for your own product, service or account.
- Suggest that your version is the official one, or that Phygital-Brain made, checked or supports it.

## Other projects called Engram

Phygital Engram is not related to other projects called Engram. The name here always comes with "Phygital". Please keep it that way, so people can tell them apart.
